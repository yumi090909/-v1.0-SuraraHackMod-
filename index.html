Catchon / すららの問題を、一瞬で。

選択式問題の正解をハイライトし、入力式問題の正解を自動入力するユーザースクリプト。 画面右上のフローティングパネルから、すべての機能をワンクリックで切り替えられます。

はじめる FAQ を見る 0909Groupに参加！
Scroll

主な機能

シンプルなのに、必要なものは全部入り。

✦

選択式ハイライト

正解の選択肢を紫のグローで強調表示。どれを選べばいいか、もう迷わない。

⌨

入力式 自動入力

テキスト・数値・テキストエリアの正解を自動でフォームに書き込みます。

⟳

リアルタイム追従

問題が切り替わると自動で再実行。手動操作は一切不要です。

◈

ドラッグ可能な GUI

画面右上のパネルは自由に移動可能。各機能の ON / OFF もその場で切替。

インストール

以下のコードをコピーして、Tampermonkey に貼り付けてください。

surara-hack-mod.user.js 

  


  

    ⚠ 実行にはテンパーモンキーが必要です。

    Tampermonkey を未導入の場合は、先に
    Chrome ウェブストア
    からインストールしてください。
  







  

    
よくある質問

    
導入前によく寄せられる質問をまとめました。

  


  

    

      
このスクリプトは何をしますか？

      

        Catchon / すららの選択式問題の正解をハイライトし、入力式問題の正解を自動入力するユーザースクリプトです。
        画面右上に表示されるパネルから、各機能を個別に ON / OFF できます。
      

    


    

      
導入に必要なものはありますか？

      

        ブラウザ拡張機能「Tampermonkey」が必要です。
        Chrome ウェブストア
        からインストールできます。
      

    


    

      
パネルが表示されません。

      

        問題ページを開いた状態でページを再読み込みしてください。
        本スクリプトはトップフレームでのみ動作する仕様です。
        それでも表示されない場合は、Tampermonkey の管理画面でスクリプトが有効になっているか確認してください。
      

    


    

      
対応ブラウザを教えてください。

      

        Tampermonkey が動作するブラウザであれば基本的に対応しています（Chrome / Edge / Firefox など）。
      

    


    

      
利用は無料ですか？

      

        はい、個人利用の範囲で無料でご利用いただけます。
        詳細な条件については
        利用規約
        をご確認ください。
      

    


    

      
不具合や要望はどこに連絡すればいいですか？
